# Cardio-Risk-Predictor

A machine learning web application built with Streamlit to predict cardiovascular disease risk based on user health parameters.

## 🚀 Features
* Interactive risk prediction dashboard using Plotly charts.
* Batch CSV data processing support.

## 🛠️ Tech Stack
* **Python**, **Streamlit**, **Scikit-Learn**, **Pandas**, **Plotly**
